# Experiment Protocol: Validating TACS and IPR (Multimodal Entity Indexing)

[![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.24356442-1b6fb5)](https://doi.org/10.5281/zenodo.24356442)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Pre-registration draft for a controlled experiment on whether the text that accompanies an image (file name, alt text, caption) affects how easily the image is found in search.

**Status:** draft v0.3 (19 November 2026). Not yet pre-registered. One external reviewer has commented; the comments are recorded in the review log inside the PDF. No data have been collected.

## Contents

- `experiment-protocol-tacs-ipr-v0.3.pdf`: the current protocol.
- `experiment-protocol-tacs-ipr-v0.2.pdf`, `experiment-protocol-tacs-ipr-v0.1.pdf`: earlier versions, kept for the record.
- `CITATION.cff`: citation metadata.
